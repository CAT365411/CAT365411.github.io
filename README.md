# LibreHub - Digital Freedom & Open-Source Toolkit

LibreHub is a lightweight, client-side web utility suite hosted via GitHub Pages. It provides privacy tools, open-source resource links, and lightweight web arcade games directly in the browser with zero tracking.

## Features
- **Privacy Utilities:** Password Generator & Base64 Encoder/Decoder.
- **Open-Source Spotlight:** Quick links to indie dev tools like Godot Engine.
- **Mini Web Arcade:** Canvas-based retro mini-games.
- **Support Links:** Decentralized contribution options (XMR / LTC).
