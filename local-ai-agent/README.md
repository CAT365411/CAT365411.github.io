# Local AI Agent App

A web-based control panel and background agent for local PC automation, real-time screen streaming, and task execution.

## Features

- **Live Screen Streaming:** Real-time desktop feed powered by WebSockets.
- **Autonomous Task Execution:** High-level prompt execution for PC actions and shell automation.
- **Customizable Dashboard UI:** Tailwind CSS dashboard with dark/light themes and custom color preferences.
- **Session Authentication:** Built-in cookie-based authentication and login flow.
