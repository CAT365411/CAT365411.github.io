# Contributing to LibreHub

Thank you for considering contributing to LibreHub!

## How You Can Help
- **Add Utilities:** Suggest or code new 100% client-side privacy or developer tools.
- **Improve UI/UX:** Enhance responsiveness, dark/light themes, or accessibility.
- **Arcade Games:** Add lightweight HTML5 canvas mini-games.

## Contribution Steps
1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/AmazingFeature`).
3. Commit your changes (`git commit -m 'Add some AmazingFeature'`).
4. Push to the branch (`git push origin feature/AmazingFeature`).
5. Open a Pull Request.
